# Phase 9 Interim Manuscript — Credit-Selected NIFTY OTM6/7/8

## Abstract
This phase tests a three-leg NIFTY option structure on both calls and puts four trading sessions before the nearest listed expiry at 10:00 IST. For each side, the entry credit is OTM7 + OTM8 - OTM6. The side with the higher positive credit is selected. A 90% of flatline target is tested, while the stop-loss multiple is selected from 0, 0.50, 0.75, 1.00, 1.25 and 1.50 times the initial credit using a chronological 60/20/20 development/validation/test split. The completed GitHub Actions run evaluated 56 executable trades and 26 skipped candidates. The validation procedure selected the no-stop baseline. The untouched test segment contained 12 trades, with mean net P&L ₹1,626.73 and a bootstrap 95% CI of approximately ₹-1,946 to ₹3,869. This interval includes zero, so the test does not establish a statistically reliable positive expectancy.

## Research Questions
1. Does selecting the larger positive 10:00 credit between the call and put structures produce positive net P&L after execution costs?
2. Does a fixed stop-loss improve the chronological validation performance relative to no stop?
3. How often does the 90%-flatline target trigger versus expiry or stop?
4. Is the result stable after transaction costs and slippage?

## Locked Method
- Entry: fourth prior trading session before actual nearest listed expiry, 10:00 IST.
- ATM: nearest 50-point strike, midpoint ties upward.
- Put: +1 OTM6 PE, -1 OTM7 PE, -1 OTM8 PE.
- Call: +1 OTM6 CE, -1 OTM7 CE, -1 OTM8 CE.
- Selection: larger positive credit.
- Target: 90% of post-entry-slippage flatline credit.
- Stop grid: 0, 0.50, 0.75, 1.00, 1.25, 1.50× initial credit.
- Trigger: minute close; execution: first common subsequent option-bar open.
- Expiry fallback: 15:29 IST.
- Slippage: 0.10 premium points per execution.
- Brokerage: ₹10 per unique executed order, plus exchange/SEBI/stamp/STT/GST schedule.

## Stop-Loss Finding
The validation segment selected the **no-stop baseline (0×)** from the pre-specified grid. Therefore this phase did not find evidence that the tested fixed credit-multiple stops improved the validation objective sufficiently to justify adding a stop. This is a data result, not a claim that no stop can ever work; alternative stop definitions would require a separately locked research phase.

## Interpretation
The test segment is encouraging in realized arithmetic terms but statistically uncertain. The confidence interval spans zero and the test has only 12 trades. The correct scientific interpretation is therefore that the rule produced a positive sample outcome under the locked assumptions, while the evidence is insufficient to establish a stable trading edge.

## Limitations
1. The sample is restricted to the available 2025–2026 intraday option dataset.
2. The dataset source is public rather than exchange-licensed tick/bid-ask history.
3. Execution is represented by adverse premium-point slippage rather than reconstructed bid/ask order-book fills.
4. Only one target definition and one fixed-stop grid were primary-tested in this phase.
5. The test sample is small.
6. The full trade-level result files were generated by CI but were not persisted because the final push encountered a non-fast-forward rejection; this must be repaired before the phase is marked fully reproducible.
